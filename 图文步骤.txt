第①步：在 GitHub 网页建一个“空仓库”

  2) 点右上角 ＋（加号）→ 选 New repository

      │                                          │

第⑤步：开启 GitHub Pages（网页，约 1–3 分钟生效）
----------------------------------------------------------------
  1) 在仓库页点顶部 Settings（齿轮图标）
  2) 左侧菜单点 Pages
  3) Build and deployment 区域这样填：

      ┌──────────────────────────────────────────┐
      │  Source : Deploy from a branch   ←选这项  │
      │  Branch : [ main  ▼ ]            ←选 main │
      │  Folder : [ / (root) ▼ ]        ←选根目录 │
      │  [ Save ]                                     │
      └──────────────────────────────────────────┘

  4) 点 Save，等 1–3 分钟
  5) 再回 Settings → Pages，顶部出现绿色对勾 + 网址：
        https://wking-jj.github.io/WKing/
  6) 浏览器打开这个网址，看到 WKing 站点即大功告成 🎉

以后怎么更新内容
----------------------------------------------------------------
  改完文件后，在 GitHub Desktop 里：
     ① 左下角写一句摘要（如“更新首页”）
     ② 点 [ Commit to main ]
     ③ 点 [ Push origin ]
  → 网站约 1 分钟后自动更新，不用再进设置。

【备选】如果你坚持用命令行（容易卡，慎选）
================================================================
  用 Git Bash（开始菜单搜 Git Bash）：
      cd /d/wangrlly/Documents/wordbuddy/wking-site
      git push -u origin main
  登录框：用户名 WKing-JJ；密码栏粘 PAT（ghp_...，不是账户密码）

  常见坑：
   • 打不开 Git Bash → 没装 Git，去 https://git-scm.com/ 装
   • 路径报错 → Git Bash 用 /d/...（正斜杠），PowerShell 用 D:\...（反斜杠）
   • 一次只粘一行并回车，不要两行一起粘
   • 生成 PAT：头像→Settings→Developer settings→Personal access tokens
     →Tokens(classic)→Generate，勾 repo，Generate 后复制 ghp_ 那串
